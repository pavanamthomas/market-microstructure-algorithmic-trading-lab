# Data policy

All series in this repository are simulated or closed form.

There is no vendor file, no exchange dump, and no scraped page. `examples/run_flagship.py` draws from `numpy.random.Generator` with an explicit seed. Bounce prints in the Roll test are generated by `bounce_trades`.

Do not add a market-data client. If a later experiment needs public sample data, it must be documented here with a licence, a retrieval date, and a statement of what the file is allowed to be used as (illustration, not a finding about that venue).
